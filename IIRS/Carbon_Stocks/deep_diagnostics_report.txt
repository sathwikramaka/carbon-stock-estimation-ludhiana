========================================================================
  A2. HOW DO THE SOIL VARIABLES RELATE TO EACH OTHER?
========================================================================
In real soil, sand and clay are strongly NEGATIVELY correlated (more of
one means less of the other), and sand is negatively related to organic
carbon. Positive correlations everywhere mean the layers are not
independent measurements.

                sand_pct    clay_pct     bd_gcm3    SOC_mean
sand_pct          1.0000      0.8393      0.9541      0.8956
clay_pct          0.8393      1.0000      0.9463      0.9498
bd_gcm3           0.9541      0.9463      1.0000      0.9660
SOC_mean          0.8956      0.9498      0.9660      1.0000

sand vs clay correlation = +0.8393
  Expected roughly -0.5 to -0.9 for real texture data.
  A strong positive value means these are not true texture fractions,
  or all layers were interpolated from the same coarse surface.

========================================================================
  A3. CAN A SINGLE SOIL VARIABLE REPLACE THE WHOLE MODEL?
========================================================================
If one predictor alone reaches nearly the full R2, the other features add
nothing and the model is a one-to-one mapping, not a learned relationship.

predictors                                R2
--------------------------------------------
full feature set                      0.9665
sand + clay + bd only                 0.9548
bulk density alone                    0.9499
clay alone                            0.9431
sand alone                            0.9036
longitude + latitude only             0.6864

If 'longitude + latitude only' scores highly, the model is mostly
learning WHERE a cell is, not what its soil is like.

========================================================================
  B2. IS RAINFALL JUST A MAP OF WHERE YOU ARE?
========================================================================
Fitting rainfall from longitude and latitude alone. A very high R2 means
rainfall is a smooth geographic surface with no local detail, so the
model can use it as a substitute for coordinates.

  Rabi_Preci     predicted from lon/lat:  R2 = 0.9995
  Kharif_Pre     predicted from lon/lat:  R2 = 0.9996
  DEM_mean       predicted from lon/lat:  R2 = 0.7833
  LST_Sept20     predicted from lon/lat:  R2 = 0.9998
  NDVI_May25     predicted from lon/lat:  R2 = 0.6936

Values near 1.00 indicate a purely spatial surface. Values near 0.5 or
lower indicate the variable carries genuine local information.

========================================================================
  SUMMARY
========================================================================
Read the verdicts above in this order:

A1/A2  If soil profiles are few and sand/clay correlate positively, the
       soil layers are one coarse product, not independent measurements.

A3     If a single variable or plain coordinates reach nearly the full
       R2, the below-ground model is a lookup, not a learned relationship.

A4     If SOC is already in the full grid file, the prediction step is
       unnecessary for the carbon estimate and should be reframed as a
       validation exercise rather than a requirement.

B2/B3  If rainfall is ~1.00 predictable from coordinates, and coordinates
       alone rival the full model, then Rabi_Preci is a position proxy.
       The fix is not better rainfall data; it is stating that the model
       captures a spatial gradient rather than a rainfall-yield process.
